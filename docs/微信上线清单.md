# 微信小程序 SaaS 上线清单

## 一、小程序注册
1. 在 [微信公众平台](https://mp.weixin.qq.com) 注册小程序，获取 **AppID / AppSecret**
2. 完成主体认证（企业认证后可开通微信支付）
3. 开发管理 → 服务器域名，配置 request 合法域名（必须 **HTTPS**）

## 二、配置到本项目
编辑 `config/default.js`：
```js
wechat: {
  appId: 'wx你的AppID',
  appSecret: '你的AppSecret',
  mchId: '你的商户号',
  payApiV3Key: '你的APIv3密钥',
  notifyUrl: 'https://你的域名/api/wx/pay/notify',
  mock: false   // 关闭模拟模式
}
```

## 三、微信支付
1. 商户平台申请 **JSAPI支付**，关联小程序
2. 下载 API 证书（apiclient_key.pem），实现 v3 下单签名（`WechatService.createJsapiOrder` 内扩展）
3. 配置支付回调地址（notifyUrl），校验回调签名后调用 `OrderManager.handlePayNotify`

## 四、部署
1. 云服务器（2C4G起步）+ 域名 + SSL证书
2. 建议使用 PM2 守护：`pm2 start src/index.js --name linlituan`
3. Nginx 反代 80/443 到 3100 端口，配置 HTTPS

## 五、合规注意
- 电商类目需要营业执照
- 食品类商品需上传食品经营许可证
- 小程序隐私协议需声明收集的信息范围（手机号、地址等）
- 支付需对账，建议接入微信支付账单下载做日终对账

## 六、验收清单
- [ ] AppID/Secret 已配置，mock=false
- [ ] 登录 code2Session 返回真实 openid
- [ ] 下单→支付→回调→订单状态变更 正常
- [ ] 有赞/对账单核对一致
- [ ] 域名已备案，证书有效
- [ ] 小程序隐私协议已配置
